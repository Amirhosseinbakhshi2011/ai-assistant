# دستیار هوش مصنوعی (AI Assistant)

یک دستیار هوش مصنوعی دسکتاپ مدرن، ماژولار و قابل توسعه نوشته‌شده با Python.

پشتیبانی کامل از زبان فارسی و انگلیسی، ذخیره تاریخچه گفتگوها، مدیریت خطا و آماده برای افزودن قابلیت‌های پیشرفته در آینده.

**توسعه‌دهنده:** امیرحسین بخشی  
**گیت‌هاب:** [https://github.com/Amirhosseinbakhshi2011](https://github.com/Amirhosseinbakhshi2011)

## ویژگی‌های نسخه ۱

- رابط کاربری مدرن و زیبا (customtkinter)
- گفتگو متنی با مدل‌های مختلف (OpenAI، Groq، OpenRouter و ...)
- ذخیره و بازیابی خودکار تاریخچه گفتگوها
- پشتیبانی از پاسخ جریانی (streaming)
- مدیریت خطا، تایم‌اوت و قطع اینترنت
- تنظیمات از طریق فایل `.env`
- ساختار کاملاً ماژولار و آماده توسعه

## پیش‌نیازها

- Python 3.11 یا بالاتر
- کلید API از یکی از سرویس‌های پشتیبانی‌شده (Groq، OpenRouter، OpenAI و ...)

## نصب

```bash
# کلون یا دانلود پروژه
cd ai_assistant

# ساخت محیط مجازی (توصیه می‌شود)
python -m venv venv

# فعال‌سازی محیط مجازی
# ویندوز:
venv\Scripts\activate
# لینوکس / مک:
source venv/bin/activate

# نصب وابستگی‌ها
pip install -r requirements.txt
